# 问题 → 筛选条件映射表

> 用途：把用户的口语回答，翻译成对 `query-meals` 缓存菜单的**本地**过滤/打分条件。
> 拿到菜单后不再调用 MCP，全部按本表在本地计算。

---

## 1. 答案枚举 → 内部参数

### 序章

| 问题 | 选项 | 内部参数 |
|---|---|---|
| 选店方式 | 定位 / 自选 | `storeCode` |
| 就餐方式 | 堂食 / 外带 / 外送 | `mealType = DINE_IN \| TAKE_OUT \| DELIVERY` |

### 第一幕

| 问题 | 选项 | 内部参数 |
|---|---|---|
| 预算（人均） | 20 / 30 / 50 / 不限 | `budgetPerPerson = 20 \| 30 \| 50 \| Infinity` |
| 饥饿度 | 轻 / 中 / 很饿 | `hunger = light \| normal \| heavy` |

`hunger` 影响：主食数量期望 + 份量档偏好
- `light` → 1 份主食，偏好常规/小份
- `normal` → 1 份主食 + 1 小食
- `heavy` → 1–2 份主食 + 1 小食，偏好大份/双层

### 第二幕

| 问题 | 选项 | 内部参数 |
|---|---|---|
| 风味派系 | 牛 / 鸡 / 鱼 / 素 / 随缘 | `flavor = beef \| chicken \| fish \| veggie \| any` |
| 辣度 | 不吃辣 / 微辣 / 越辣越好 | `spice = none \| mild \| hot` |

### 第三幕

| 问题 | 选项 | 内部参数 |
|---|---|---|
| 人数 | 整数 n | `people = n` |
| 甜饮 | 都要 / 只要饮料 / 只要甜品 / 都不要 | `wantDrink`、`wantDessert`（布尔） |
| 热量 | 在意 / 不在意 | `careCalories`（布尔，true 时调 `list-nutrition-foods`） |

---

## 2. 关键词识别规则（中文口语兜底）

用户不会严格按选项回答，需做关键词匹配：

```
预算：
  "20/二十/便宜/省/穷"        → 20
  "30/三十/正常/随便/一份套餐" → 30
  "50/五十/好一点/吃好的"      → 50
  "不限/不管了/今天开心"       → Infinity

饥饿：
  "不饿/嘴馋/尝个鲜/吃过饭"    → light
  "正常/一般/有点饿"           → normal
  "很饿/超饿/饿死/没吃饭"      → heavy

风味：
  "牛/牛肉/巨无霸/安格斯"      → beef
  "鸡/鸡腿/麦辣/炸鸡"          → chicken
  "鱼/鳕鱼/麦香鱼"             → fish
  "素/蔬菜/沙拉/吃草"          → veggie
  "随便/都行/你定/不知道"      → any

辣度：
  "不吃辣/不能辣/一点辣都不行" → none
  "微辣/一点点辣/可以辣"      → mild
  "很辣/越辣越好/变态辣/无辣不欢" → hot
```

## 3. 菜单字段 → 分类桶

`query-meals` 返回的每个餐品按 `category` / `name` / `tags` 归入 4 个桶：

| 桶 | 识别关键词（出现在 category 或 name 中） |
|---|---|
| `mainFood` | 汉堡、堡、卷、饭、鸡排、麦辣、巨无霸、安格斯、奥良、板烧、双层、吉士 |
| `side` | 薯条、鸡块、鸡翅、派、玉米、沙拉、小食、麦乐鸡、麦旋风（非甜品类小食） |
| `drink` | 可乐、雪碧、咖啡、茶、果汁、奶茶、矿泉水、饮料 |
| `dessert` | 冰淇淋、甜筒、圣代、麦旋风、派（甜）、蛋糕、甜品 |

> 分类以 MCP 返回的 `category` 字段为**首选**依据，关键词仅作兜底。若返回里没有该餐品，绝不虚拟创建。

---

## 4. 过滤规则

对 `mainFood` 桶：

| 条件 | 过滤逻辑 |
|---|---|
| 预算 | 单份价格 `≤ budgetPerPerson` 时优先保留；若过滤后为空，放宽到 `budgetPerPerson × 1.2` 并在结果中标注「略超预算」 |
| 风味 | `flavor ≠ any` 时，剔除明显冲突项（如用户要 beef，剔除标注 `chicken` 标签的） |
| 辣度 | `spice = none` → 剔除带「辣/香辣/麻辣」标签的；`spice = hot` → 优先保留带辣标签的 |
| 售罄 | `status === SOLD_OUT` 或 `soldOut === true` → 直接剔除 |

**空桶保护**：过滤后若某桶为空，逐步放宽（先放开辣度，再放开风味，最后放开预算），并告知用户「按你的条件没找到，已为你放宽到 XX」。

---

## 5. 份数计算

```
主食份数 = people × (hunger === 'heavy' ? 1.2 : 1)   // 向上取整
小食份数 = people
饮料份数 = wantDrink ? people : 0
甜品份数 = wantDessert ? people : 0
```
